
# 💯 100 Days of C Programming Challenge

Welcome to my **100 Days of C Programming** journey!  
This repository contains all the C programs I practiced daily as part of my effort to strengthen my fundamentals in programming and problem-solving.

## 📁 Folder Structure

Each folder represents one day of practice, starting from **Day 1** to **Day 100** (or however many days completed so far).  
Every day includes a mix of:
- Basic problems
- Logic-building exercises
- Concept-based programs (loops, arrays, functions, etc.)
- Interview-style questions
